# Interface glossary — English · Español · Tiếng Việt · ไทย

Use these exact terms everywhere in the interface so the four languages read as one product.
If a term you need is missing, choose the most common everyday word used by restaurants and
delivery apps in that language, and use it consistently within your area.

Tone
- **Español**: neutral Latin American Spanish, informal *tú* ("Elige", "Tu pedido"). Short.
- **Tiếng Việt**: friendly, neutral; address the reader as *bạn* only when needed. Short labels,
  no trailing "ạ".
- **ไทย**: polite, neutral written Thai. No ครับ/ค่ะ in labels, buttons or statuses; a short
  polite sentence is fine in longer messages. Keep common loanwords the industry already uses
  (ออร์เดอร์, เมนู, แคชเชียร์, แดชบอร์ด).
- Keep brand and product names in Latin letters: Favornoms, Stripe, Google, Supabase, QR, PIN, PWA.
- Never translate merchant content (dish names, descriptions, ingredients, options, restaurant /
  branch / brand names, addresses, notes) or data values stored or compared in code.
